# VKinder — Чат-бот для знакомств ВКонтакте

Бот для социальной сети ВКонтакте, который ищет подходящих кандидатов для знакомства на основе данных пользователя (город, возраст, пол). Проект является дипломной работой по курсу «Python-разработчик с нуля».

## Возможности бота
* Анализ профиля пользователя и автоматический подбор противоположного пола, ровесников из того же города.
* Обход лимита ВКонтакте в 1000 пользователей при поиске.
* Отбор топ-3 самых популярных фотографий кандидата (по количеству лайков).
* Интерактивная клавиатура для взаимодействия (Лайк, В ЧС, Дальше).
* Сохранение истории просмотров, избранного и черного списка в базу данных PostgreSQL (кандидаты не повторяются).

## Структура проекта
* `main.py` — точка входа, инициализация бота, прослушивание сообщений LongPoll.
* `vk_client.py` — класс `VKClient` для работы с API ВКонтакте (поиск пользователей, получение фотографий).
* `db_models.py` — декларативные модели базы данных (SQLAlchemy).
* `db_crud.py` — функции для работы с базой данных (добавление, выборка).

## Требования
* Python 3.9+
* PostgreSQL
* Токен сообщества ВКонтакте
* Токен пользователя ВКонтакте
